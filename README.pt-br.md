<h3>Projeto full-stack para Autenticação e Autorização com permissões (roles)</h3>

Ao executar o **backend**, automaticamente é criado 3 usuários com suas respectivas permissões cadastradas no
sistema (ADMIN, MANAGER e USER), onde apenas o ADMIN tem acesso aos usuários e permissões para alteração, caso necessário.<br>

Ao fazer o login no **frontend**, é gerado um token para o usuário ter a permissão de usar o sistema, e ao
sair, esse token é limpo, para manter a segurança da aplicação.<br>

<h3>🛠 Tecnologias e Detalhes Técnicos</h3>

- **Banco de Dados**: PostgreSQL.
- **Backend**: Java com Spring.
- **Frontend**: Angular.
