## 🇺🇸 - About the project

**Authentication and Authorization with RBAC (Role-Based Access Control)**

Full-stack project for Authentication and Authorization with role-based permissions.

When running the **backend**, three users with their respective permissions (ADMIN, MANAGER, and USER)
are automatically created in the system. Only the ADMIN has access to users and permissions for modifications, if necessary.

Upon logging in on the **frontend**, a token is generated to grant the user access to the system. When logging
out, this token is cleared to maintain application security.

**🛠 Technologies and Technical Details**

- **Database**: PostgreSQL.
- **Backend**: Java with Spring.
- **Frontend**: Angular.

## 🇧🇷 - Sobre o projeto

**Autenticação e Autorização com RBAC (Role-Based Access Control)**

Projeto full-stack para Autenticação e Autorização com permissões (roles).

Ao executar o **backend**, automaticamente é criado 3 usuários com suas respectivas permissões cadastradas no
sistema (ADMIN, MANAGER e USER), onde apenas o ADMIN tem acesso aos usuários e permissões para
alteração, caso necessário.

Ao fazer o login no **frontend**, é gerado um token para o usuário ter a permissão de usar o sistema, e ao
sair, esse token é limpo, para manter a segurança da aplicação.

**🛠 Tecnologias e Detalhes Técnicos**

- **Banco de Dados**: PostgreSQL.
- **Backend**: Java com Spring.
- **Frontend**: Angular.
