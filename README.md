<h3>Full-stack project for Authentication and Authorization with role-based permissions</h3>

When running the **backend**, three users with their respective permissions (ADMIN, MANAGER, and USER)
are automatically created in the system. Only the ADMIN has access to users and permissions for modifications, if necessary.<br>

Upon logging in on the **frontend**, a token is generated to grant the user access to the system. When logging
out, this token is cleared to maintain application security.<br>

<h3>🛠 Technologies and Technical Details</h3>

- **Database**: PostgreSQL.
- **Backend**: Java with Spring.
- **Frontend**: Angular.
